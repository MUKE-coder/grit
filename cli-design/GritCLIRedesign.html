Rules

The big wordmark appears once

Show it on grit new and grit version. Every other command gets a one-line header: mark, command, version.

Report results, not activity

A finished step is a green check and a noun. Only the step that is running gets a spinner. Timings sit dim on the right.

Bold is the emphasis, brand is the action

Brand color marks things the developer can type or pick. Names and totals are bold in the default foreground.

Warnings say what still works

Title, consequence, fix. The fix is a command in brand color that can be copied as is.

Two-space gutter, aligned columns

Everything starts at column 3. Descriptions and comments line up in a second column and are muted.

No rules made of equals signs

Separate groups with one blank line. A single faint line is allowed above the URL table and nowhere else.
