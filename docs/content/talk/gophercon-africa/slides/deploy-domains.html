Domains, per service

Certificates
Traefik issues them. Behind Cloudflare, set SSL to Full (strict)

Two of these are the ones that fail quietly: a public variable set at runtime instead of build time is simply absent from the built frontend, and Cloudflare on Flexible gives you a redirect loop that looks exactly like an application bug.

gritframework.dev

Say the build-time distinction clearly, because it is the single most common deployment failure in any Next.js stack and nothing warns you. APP_URL matters more here than people expect: with local disk storage every uploaded file's URL is built from it, so a wrong value means every image on the site is broken while the upload itself succeeded.
