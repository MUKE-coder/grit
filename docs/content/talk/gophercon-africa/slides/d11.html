You are fluent in Go. Then you open the React project.

Nobody funds a frontend developer for an internal admin panel. So you learn just enough React to build screens you are not proud of, slowly, on every project.

gritframework.dev

This is the room. Say it plainly and then wait, because the laugh is the data. Be careful not to sneer at frontend work: it is a real craft and the point is the opposite. A backend engineer doing it under protest, with a deadline, having learned the minimum, produces bad frontend. That is not a frontend problem, it is an allocation problem. And this is the one people are least willing to say out loud in a planning meeting, so it never gets budgeted. It just quietly eats a third of the project.
