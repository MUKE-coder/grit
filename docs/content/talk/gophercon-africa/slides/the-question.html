So the question is not which library

Can the shape of an application be generated, owned outright by you, and still improve after you own it?

gritframework.dev

This is the hinge of the whole talk. Read it slowly and then stop. Three clauses, and they fight each other. Generated is easy, lots of tools do it. Generated and owned by you is harder. Generated, owned, and still improving afterwards is the actual problem, because the moment code is yours, nobody can fix it but you. Everything after this slide is the answer to that sentence.
