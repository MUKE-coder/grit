Two numbers and one sentence. Say the numbers, then take the sentence in three pieces. Orientation first: the rotation lives in metadata, so a naive resize produces the sideways thumbnail everyone has shipped once. Then privacy, and this one is free rather than clever: the output is re-encoded from decoded pixels, so there is nowhere for the GPS to survive. You get the right answer by doing the work in the right order. Then the attack. A solid-colour PNG can be 165 kilobytes on disk and a gigabyte decoded, so the limit has to be on the decoded pixel count and it has to be checked before decode. Once Decode runs, the memory is already yours.
