D12

Asking a model to write it is not free.

Seventy-four thousand lines is about three quarters of a million output tokens, before the first correction. You pay it again on the next project, and it writes something different.

gritframework.dev

This is the newest problem on the list and the one the room is living through right now. Be fair to the tools: an agent writing this is genuinely impressive and it is fast. The objection is not that it does not work. It is three things it cannot do. It cannot be free, and the bill arrives again on the next project. It cannot be identical, so the auth it writes you in March and the auth it writes you in June are different code with different bugs. And because they are different, a fix you make in one project has nowhere to go: this is D1, the copy-paste start, with a bill attached. And you still own the review. Seventy-four thousand lines nobody on the team has read is not a head start.
