Three cards. The first two are the easy part of the idea, the third is the part that makes it safe. A list of framework-owned files is how upgrade knows what it may rewrite. That alone is not enough, because you might have edited one of them. So every generated file is hashed into a manifest when it is written. On upgrade, a file whose hash has moved is not rewritten. It is reported. You get told that your edit and the framework fix disagree, which is the only honest thing a tool can do there.
