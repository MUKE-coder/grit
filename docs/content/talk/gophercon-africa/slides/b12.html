B12 · nobody asks until it happens

“What if two people edit the same record?”

Last write wins is not a policy. It is a data-loss feature with a friendly name.

gritframework.dev

This is the only one on the list that no client asks in advance. It arrives as "my changes disappeared", weeks after launch, and it is almost impossible to reproduce. Two people open the same invoice. One saves at 10:02, the other at 10:03 from a form loaded at 10:01. The second save silently reverts the first. The fix is not a lock. It is a conditional write, a refusal the interface can act on, and telling the human what happened.
