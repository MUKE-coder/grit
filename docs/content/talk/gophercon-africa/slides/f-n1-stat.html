Three numbers. Let the zero land on its own. Every one of those 201 queries is a primary key lookup that returns in a quarter of a millisecond. A slow query log will never show you one of them. An alert on p95 tells you the page is slow and nothing about why. The measurement that finds it is queries counted inside a single request, which only something living in the process can do. That is the whole argument for observability being in the framework rather than bolted on.
