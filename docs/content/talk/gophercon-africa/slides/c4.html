C4 · why the other three work

Convention is what makes it possible.

One folder layout. One response envelope. One place a route is registered. A generator cannot write into a project whose shape it has to ask about.

gritframework.dev

This is the idea people argue with, so make the argument rather than the assertion. Every convention here exists because something had to be mechanical. The generator writes a route by finding one line in one file. That only works if that line is in the same place in every project, which means the layout is not yours to rearrange. That is a real trade. You lose the freedom to lay the project out your way. What you buy with it is a generator that works, an upgrade that works, and twenty projects you can move between without reading the README.
