C1 · the unit of generation

A resource is the only thing that spans the whole stack.

So it is the thing worth generating. Not a file. Not a layer. The invoice, from the column to the form field.

gritframework.dev

This is the load-bearing idea, so say it slowly. A scaffolder that generates a model is almost useless, because the model was never the expensive part. The expense is that one concept, invoice, has to be spelled correctly in nine places. Generate the layer and you have automated the easy bit. Generate the resource and the nine places agree by construction.
