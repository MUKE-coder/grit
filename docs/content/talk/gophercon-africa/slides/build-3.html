Step three · run it

$ grit migrate
$ grit seed Patient --count 50000
$ grit start

The seed is not optional theatre. Fifty thousand patients is where you find out whether the list page works.

gritframework.dev

Three commands. The middle one is the one to defend. Seeding before you look is a habit worth arguing for. A list page at ten rows tells you nothing: the sort is instant, there is one page, and the N+1 costs ten queries. At fifty thousand you find the missing index on the first click. grit start brings up the API, both frontends and the infrastructure together, which is D2 gone.
