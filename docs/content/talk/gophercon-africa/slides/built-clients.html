Read three of the pills, not all eight. Then the line, which is the actual point of the slide. These were not demos. Each one was built to find the place where the framework runs out, and each one found several. The storefront found seven faults. The contact application found a hundred and nine, and the useful detail is that nearly all of them were small, obvious and invisible until somebody tried to use the thing for an afternoon.
