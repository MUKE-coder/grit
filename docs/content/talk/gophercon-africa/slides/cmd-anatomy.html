The command, before the fields

One verb, one noun, one description.

grit generate resource Invoice --fields "..." --owned-by user

what to make  resource, field, job, sequence, workflow, mail
the name  singular and PascalCase. The plural is derived
the description  the fields, comma separated
what kind of thing it is  owned, tenant-owned, append-only, public, tree

The last group is the one worth knowing. It does not add columns: it decides who may read a row, whether a row can ever change, and whether the internet can see it.

gritframework.dev

Thirty seconds on this, then the fields. The name is singular and PascalCase, and everything else is derived from it: the table is invoices, the route is /api/v1/invoices, the file is invoice.go, the screen is Invoices. You name it once. Then the part people miss, so say it slowly: the flags on the end are not more columns. --owned-by user scopes every query to the person who made the row. --append-only means the rows can never be edited or deleted. --public adds a read-only surface for the internet. They change what kind of thing the resource is, which is why they are flags and not fields.
