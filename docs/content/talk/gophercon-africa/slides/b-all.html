Fourteen questions, before anyone mentions the feature

B1  “Can different people see different things?”

B2  “What happens if we get hacked?”

B3  “Does it work without internet?”

B4  “How will we know when it breaks?”

B5  “Is any of this backed up?”

B6  “What if it gets busy?”

B7  “Who changed this?”

B8  “Can it take a ten megabyte photo?”

B9  “Can two of our clients use one system?”

B10  “Does the screen update by itself?”

B11  “Can we switch it on for one customer?”

B12  “What if two people edit the same record?”

B13  “Does it talk to our other systems?”

B14  “Can you delete one person's data?”

gritframework.dev

Read two or three of these in the client's voice. They are quotes. Do not read all fourteen. Then the line that sets up the section: the honest answer to every one of these is "yes, in about three weeks", and the client hears that as a no.
