How to read one of these

A field describes itself, left to right.

cycle : select[monthly, annually] if kind == recurring

the name  the column, and the JSON key
the type  decides the column, the input, the validation
its argument  in brackets. Only some types take one
the condition  when this field applies at all

Labels come from the values: monthly reads as Monthly. Write one only when it differs. And kind is another field on this resource, recurring one of the values it stores.

Put this up before you type anything, because the commands on the next slides are unreadable until somebody has seen this once. Read it out loud as a sentence: a cycle, which is a choice of monthly or annually, if the kind is recurring. Then the two things people ask. Labels are derived, so you write the values and the forms say Monthly. And the condition names a sibling field and one of its stored values, which is why it is kind and recurring rather than Kind and Recurring.
