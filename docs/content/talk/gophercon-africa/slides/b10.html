B10 · the demo expectation

“Does the screen update by itself?”

Someone else's write appearing without a refresh. Obvious to ask for, and usually answered with a second piece of infrastructure to operate.

gritframework.dev

Every client has used a chat app, so this is now the baseline expectation rather than a feature request. The usual answer is a websocket server, a message broker and a second thing in the deployment that can fall over. That is why it gets dropped: the cost is not the code, it is the operations.
