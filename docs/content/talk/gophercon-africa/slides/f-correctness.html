409 Conflict

{
  "code": "VERSION_CONFLICT",
  "message": "this invoice changed while you were editing it",
  "current_version": 9
}

A number, not a string. The interface can offer to reload, show the difference, or retry, because it was told enough to act.

gritframework.dev

Point at the nine and say it is a number. That sounds like a joke and it is a real bug that shipped: it went out as a quoted string, so every client that compared versions compared text, and the comparison was silently wrong. The shape matters more than the mechanism. A 409 that just says conflict leaves the frontend with nowhere to go but an alert box. A 409 that carries the version the server actually holds lets the interface do something useful, and that is the difference between handling a conflict and reporting one. Underneath it is an If-Match header and a conditional update. Two people, one record, and the second save is refused rather than silently winning.
