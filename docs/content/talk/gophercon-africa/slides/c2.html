The anxiety about any framework is lock-in, and the honest way to answer it is to show the output. What you get is Go. If Grit disappeared tonight, your application compiles tomorrow, because there is nothing of Grit inside it. That is the difference between a generator and a runtime. The cost of that choice is real, and I name it on the next idea: once the code is yours, nobody can fix it but you.
