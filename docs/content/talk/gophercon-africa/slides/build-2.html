Step two · the resources

$ grit generate resource Patient \
    --fields "name:string, dob:date, phone:tel, photo:file"

$ grit generate resource Visit \
    --fields "patient:belongs_to, notes:richtext, fee:money"

gritframework.dev

Two commands, and the second one is the interesting one. patient:belongs_to is the whole relationship. Foreign key, constraint, preload, the nested type on the frontend, and a searchable dropdown in the visit form that shows the patient's name rather than a UUID. fee:money is the rounding bug you did not ship. notes:richtext is an editor you did not install. Nothing on this slide is a configuration file. The description is the configuration.
