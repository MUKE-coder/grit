One line

$ grit generate resource Invoice \
    --fields "number:string, total:money, due:date, client:belongs_to[Client]"

Four field types. One of them is a relationship. That is the entire input.

gritframework.dev

Read the command out loud, slowly. Point at belongs_to. One word, and you get the foreign key, the constraint, the preload, the nested TypeScript type and a searchable dropdown in the form that loads the related rows. Point at money. That is the bug from D3, solved by the type system rather than by discipline.
