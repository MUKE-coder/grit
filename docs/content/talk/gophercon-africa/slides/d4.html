D4

CRUD hell.

List, form, pagination, search, filters, sorting. Twenty tables, twenty times. It is not intellectually hard, which is exactly why it is expensive.

gritframework.dev

Two words on the slide. Say them, then say the subtitle, then move. The argument is counter-intuitive and worth making clearly: the reason CRUD UI eats weeks is not that it is difficult. It is that it is boring, so it gets no design attention, so every table gets a slightly different answer.
